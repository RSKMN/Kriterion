Kriterion — Code Workspace

This folder contains the frontend and backend scaffolding for the Kriterion personal finance tracker.

Structure:

- `frontend/` — React + Vite frontend (TypeScript)
- `backend/` — Spring Boot backend (Java, Maven)
- `docker/` — Docker placeholders and compose
- `docs/` — architecture and API artifacts
- `scripts/` — helpful dev scripts (DB init, etc.)

Files are placeholders and explanatory notes only; no business logic is implemented.
