Abstract: Personal Expense Tracker Web App
The Personal Expense Tracker Web App is a full-stack web application developed using HTML, CSS, and JavaScript for the frontend, with React.js to create a responsive and interactive user interface. The backend is implemented using Java with Spring Boot (or Node.js) to handle business logic and RESTful API services, while MySQL is used for secure and structured data storage. The application allows users to register and log in securely, record daily income and expenses, categorize transactions, and track financial activities over time.
Users can set monthly budgets, view real-time balance updates, and analyze their spending patterns through graphical representations such as charts and reports generated using libraries like Chart.js. The system ensures data privacy through authentication and proper database management, enabling users to retrieve and update their financial records efficiently. Version control using Git supports collaborative development and maintenance.
This project demonstrates the practical application of modern web development technologies and full-stack concepts to build a scalable, user-friendly, and secure personal finance management system that helps users make better financial decisions and improve budgeting habits.
